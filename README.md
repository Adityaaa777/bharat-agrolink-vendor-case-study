# Bharat AgroLink — Vendor App Case Study

A portfolio case study by **Shruti** covering the Vendor App UX and visual design. This repository contains the static website, not the vendor product. Open `index.html` to review it locally.

The screen images are optimized versions of supplied 4× PNG exports. [Screen sources](screen-sources.html) maps each displayed image to its exact original filename. The case study describes design decisions and validation opportunities without claiming measured product outcomes.

GitHub Pages can publish this repository from the `main` branch and `/ (root)` folder. No build command or backend is required.
